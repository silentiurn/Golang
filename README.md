## Описание проектов

### 1. piscinego
Учебные задания для освоения основ Go.  
- Практика с базовыми структурами данных, циклами, функциями.  

### 2. go-reloaded
Текстовый редактор на Go.  
- Позволяет редактировать текстовые файлы через командную строку.  
- Преобразует числа, изменяет регистр слов, нормализует пунктуацию и корректирует артикли в текстовых файлах.  

### 3. ascii-art-web-stylize
Веб-приложение для генерации ASCII-арта.  
- Пользователь может загружать текст и получать ASCII-арт через удобный веб-интерфейс.  
- Основные файлы: `main.go`, `handlers.go`, `ascii.go`.  
- Структура проекта включает:  
  - `banners/` — готовые ASCII-шаблоны  
  - `templates/` — HTML-шаблоны  
  - `static/` — CSS и JS для фронтенда
