# Go Course Projects

Добро пожаловать! 🎉  
В этом репозитории хранятся **все учебные проекты и программы**, которые я выполняла с начала курса по Go.  
Всего более **100 проектов**, направленных на изучение основ языка Go, работы со строками, числами, файловой системой и логикой программирования.

Проекты помогают изучить:
- Основы языка Go  
- Работа с файлами и файловой системой
- Манипуляции со строками и числами  
- Форматирование текста и работу с аргументами командной строки  
- Использование стандартных пакетов Go
